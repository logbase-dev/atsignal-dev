# 블로그 관리 시스템 설계 문서

### 1. 개요

- 목적: 관리자 페이지에서 블로그 포스트를 생성/수정/삭제
- 참고 구조: FAQ와 Page 구조 활용
- 다국어: 한국어(필수), 영어(선택)
- 저장소: Firestore `blog` 컬렉션

### 2. 데이터 모델 (BlogPost)

### 2.1 기본 필드

```tsx
interface BlogPost {
  id?: string; // Firestore 문서 ID
  title: LocalizedField; // 제목 (ko: 필수, en: 선택)
  slug: string; // URL용 슬러그 (영문, 소문자, 하이픈)
  content: LocalizedField; // 본문 내용 (ko: 필수, en: 선택)
  excerpt?: LocalizedField; // 요약/설명 (선택)

  // 카테고리 관련
  categoryId?: string; // 블로그 카테고리 ID (선택)

  // 발행 관련
  published: boolean; // 발행 여부
  publishedAt?: Date; // 발행일시 (published=true일 때 자동 설정)

  // 메타데이터
  tags?: string[]; // 해시태그 배열
  thumbnail?: string; // 썸네일 이미지 URL
  featuredImage?: string; // 대표 이미지 URL

  // 에디터 설정
  editorType?: "nextra" | "toast"; // 에디터 타입
  saveFormat?: "markdown" | "html"; // 저장 형식

  // 활성화 상태
  enabled: {
    ko: boolean; // 한국어 활성화
    en: boolean; // 영어 활성화
  };

  // SEO 설정
  metaTitle?: LocalizedField; // SEO 메타 제목 (선택)
  metaDescription?: LocalizedField; // SEO 메타 설명 (선택)
  metaKeywords?: string[]; // SEO 키워드 (선택)

  // 순서/우선순위
  isFeatured?: boolean; // 추천 포스트 여부
  order?: number; // 정렬 순서

  // 조회수 (추후 확장)
  views?: number; // 조회수 (기본값: 0)

  // 타임스탬프
  createdAt?: Date;
  updatedAt?: Date;

  // 작성자 정보
  createdBy?: string; // 생성한 관리자 ID
  updatedBy?: string; // 수정한 관리자 ID
}
```

### 2.2 블로그 카테고리 (BlogCategory)

```tsx
interface BlogCategory {
  id?: string;
  name: LocalizedField; // 카테고리 이름 (ko: 필수, en: 선택)
  description?: LocalizedField; // 카테고리 설명
  slug: string; // 카테고리 슬러그 (URL용)
  order: number; // 정렬 순서
  enabled: {
    ko: boolean;
    en: boolean;
  };
  createdAt?: Date;
  updatedAt?: Date;
  createdBy?: string;
  updatedBy?: string;
}
```

### 3. 입력 폼 구성

### 3.1 기본 설정 섹션

- 카테고리 선택
  - 드롭다운 (선택사항)
  - "카테고리 관리" 버튼 (모달)
- 슬러그 (Slug)
  - 자동 생성 로직:
    - 한글 제목 입력 시: 한글 → 영문 자동 번역 후 slug 생성
    - 영문 제목 입력 시: 영문 제목 기반으로 slug 자동 생성
  - 수동 수정 가능 (입력 필드에서 직접 수정)
  - 유효성 검증 (영문, 소문자, 하이픈만 허용)
  - 중복 검사 (동일 slug 존재 시 숫자 추가: `-1`, `-2` 등)
- 발행 상태
  - 체크박스: 발행 여부 (`published`)
  - 발행 시 `publishedAt` 자동 설정
- 활성화 상태
  - 한국어 활성화
  - 영어 활성화
- 추천 포스트
  - 체크박스: 추천 여부 (`isFeatured`)
- 정렬 순서
  - 숫자 입력 (`order`)

### 3.2 콘텐츠 섹션

- 언어 탭: 한국어 / English
- 제목 (Title)
  - 한국어: 필수
    - 한글 제목 입력 시 자동으로 영문 번역 후 slug 생성
    - 예: "안녕하세요" → 자동 번역 → slug: "hello" (또는 번역 결과 기반)
  - 영어: 선택
    - 영문 제목 입력 시 경로(slug)가 자동으로 생성됩니다.
    - 영문 제목이 있으면 영문 제목 기반으로 slug 생성 (우선순위)
    - 영문 제목이 없으면 한글 제목 번역 결과로 slug 생성
- 요약 (Excerpt)
  - 한국어: 선택 (SEO/목록 미리보기용)
  - 영어: 선택
- 본문 (Content)
  - 에디터 타입: TOAST UI Editor / Nextra
  - 저장 형식: Markdown / HTML (TOAST UI Editor만)
  - 한국어: 필수
  - 영어: 선택
  - 이미지 업로드 지원

### 3.3 이미지 섹션

- 썸네일 (Thumbnail)
  - 업로드
  - 미리보기
  - 삭제
- 대표 이미지 (Featured Image)
  - 업로드
  - 미리보기
  - 삭제
- 본문 이미지 삭제
  - 수정/삭제 시 Storage에서 자동 삭제 (FAQ/Page와 동일)

### 3.4 태그 섹션

- 해시태그 입력
  - 자동완성
  - 쉼표/엔터로 구분
  - 태그 목록 표시 및 제거
- 기존 태그 목록 표시

### 3.5 SEO 설정 섹션 (선택)

- 슬러그 (Slug) - 기본 설정 섹션에서 관리
  - 자동 생성: 한글 제목 → 영문 번역 → slug 변환
  - 수동 수정: slug 입력 필드에서 직접 수정 가능
  - URL 미리보기: `/blog/[slug]` 형태로 표시
- 메타 제목 (Meta Title)
  - 한국어: 선택
  - 영어: 선택
- 메타 설명 (Meta Description)
  - 한국어: 선택
  - 영어: 선택
- 메타 키워드 (Meta Keywords)
  - 쉼표로 구분

### 5. API 엔드포인트

### 5.1 포스트 관리

- `GET /api/blog` - 목록 조회
- `GET /api/blog/[id]` - 상세 조회
- `POST /api/blog` - 생성
- `PUT /api/blog/[id]` - 수정
- `DELETE /api/blog/[id]` - 삭제

### 5.2 카테고리 관리

- `GET /api/blog/categories` - 카테고리 목록
- `GET /api/blog/categories/[id]` - 카테고리 상세
- `POST /api/blog/categories` - 카테고리 생성
- `PUT /api/blog/categories/[id]` - 카테고리 수정
- `DELETE /api/blog/categories/[id]` - 카테고리 삭제

### 6. 주요 기능 요약

### 필수 기능

1. 카테고리별 분류
2. 다국어 (한국어/영어)
3. 마크다운/HTML 에디터
4. 이미지 업로드 및 관리
5. 태그
6. 발행/초안 상태
7. 검색 및 필터

### 선택 기능

1. SEO 메타데이터 -> 필요(한글제목입력시 자동번역, slug 수정가능하게.)
2. 썸네일/대표 이미지 -> 필요(포스트 작성시 첫번째 이미지를 썸네일/대표 이미지로 가능?)
3. 추천 포스트 -> 필요
4. 조회수 -> 필요(web앱에서만 조회수 증가)
5. 정렬 순서 -> 추천, 최신순ㄷ

### 7. FAQ/Page와의 차이점

- FAQ: 질문/답변, 카테고리, 레벨, 맨 상위 표시
- Page: 메뉴 연결, 라이브/드래프트, 사이트별 관리
- Blog: 발행일, 요약, 썸네일, SEO, 조회수(추후)

### 8. Slug 생성 로직

### 8.1 Slug 생성 우선순위

1. 영문 제목이 있는 경우: 영문 제목 기반으로 slug 생성
2. 영문 제목이 없는 경우: 한글 제목을 영문으로 번역 후 slug 생성

### 8.2 Slug 변환 규칙

- 소문자 변환
- 공백을 하이픈(`-`)으로 변환
- 특수문자 제거 (영문, 숫자, 하이픈만 허용)
- 연속된 하이픈 제거
- 앞뒤 하이픈 제거
- 최대 길이 제한 (예: 100자)

### 8.3 Slug 중복 처리

- 동일 slug가 존재하는 경우 자동으로 숫자 추가
- 예: `my-post`, `my-post-1`, `my-post-2`

### 8.4 한글 → 영문 번역

- 한글 제목을 영문으로 번역하는 API 또는 라이브러리 사용
- 번역 결과를 slug로 변환
- 번역 실패 시 한글을 로마자로 변환 (예: "안녕" → "annyeong")

### 9. Web 앱 UI 설계

### 9.1 블로그 목록 페이지 (`/blog`)

#### 레이아웃 구조

─────────────────────────────────────────┐
│ 카테고리 버튼 영역 (상단) │
│ [전체] [기술] [디자인] [공지사항] ... │
├─────────────────────────────────────────┤
│ │
│ 블로그 포스트 목록 (카드/리스트) │
│ - 썸네일 │
│ - 제목 │
│ - 요약 │
│ - 카테고리 │
│ - 발행일 │
│ - 조회수 │
│ │
└─────────────────────────────────────────┘

#### 카테고리 필터

- 상단에 카테고리 버튼 배치
- "전체" 버튼: 모든 포스트 표시 (기본 선택)
- 각 카테고리 버튼: 해당 카테고리에 속한 포스트만 필터링
- 활성 카테고리 버튼 시각적 표시 (배경색, 테두리 등)
- 클릭 시 URL 업데이트: `/blog?category=[categoryId]` 또는 `/blog/category/[categorySlug]`

#### 포스트 목록 표시

- 카드 형식 또는 리스트 형식
- 각 포스트 카드:
  - 썸네일 이미지 (있는 경우)
  - 제목 (클릭 시 상세 페이지 이동)
  - 요약 (excerpt)
  - 카테고리 태그
  - 발행일
  - 조회수
  - 태그 (있는 경우)

### 9.2 블로그 상세보기 페이지 (`/blog/[slug]`)

#### 레이아웃 구조

┌──────────────┬──────────────────┬──────────────┐
│ │ │ │
│ Left Sidebar│ Main Content │ Right Sidebar│
│ │ │ │
│ Most Popular│ - 제목 │ TOC │
│ or │ - 발행일 │ │
│ Category │ - 작성자 │ │
│ Posts │ - 본문 내용 │ │
│ (3~5개) │ - 태그 │ │
│ │ - 관련 포스트 │ │
│ │ │ │
└──────────────┴──────────────────┴──────────────┘

#### 왼쪽 사이드바 (Left Sidebar)

- **Most Popular Posts** (인기 포스트)
  - 조회수 기준 상위 3~5개 포스트 표시
  - 각 포스트:
    - 썸네일 (작은 크기)
    - 제목 (클릭 시 이동)
    - 조회수
- 또는 **Category Posts** (같은 카테고리 포스트)
  - 현재 포스트와 같은 카테고리의 다른 포스트 3~5개
  - 최신순 또는 조회수순 정렬
  - 현재 포스트는 제외

#### 메인 콘텐츠 영역 (Center)

- 제목
- 메타 정보: 발행일, 작성자, 카테고리, 조회수
- 썸네일/대표 이미지 (있는 경우)
- 본문 내용 (마크다운/HTML 렌더링)
- 태그 목록
- 관련 포스트 추천 (선택)

#### 오른쪽 사이드바 (Right Sidebar)

- **TOC (Table of Contents)** - 목차
  - 본문의 헤딩(h1, h2, h3 등)을 자동으로 추출하여 표시
  - 클릭 시 해당 섹션으로 스크롤 이동
  - 현재 보고 있는 섹션 하이라이트
  - 스크롤에 따라 자동 업데이트

### 9.3 반응형 디자인

#### 모바일 (768px 이하)

- 카테고리 버튼: 가로 스크롤 가능한 버튼 그룹
- 상세 페이지:
  - 왼쪽 사이드바: 상단으로 이동 또는 숨김
  - 오른쪽 사이드바 (TOC): 하단 고정 또는 드로어 형태

#### 태블릿 (768px ~ 1024px)

- 상세 페이지:
  - 왼쪽 사이드바: 메인 콘텐츠 위로 이동 가능
  - 오른쪽 사이드바 (TOC): 유지

#### 데스크톱 (1024px 이상)

- 3단 레이아웃 유지
- 왼쪽/오른쪽 사이드바 고정

### 9.4 UI 컴포넌트

#### 카테고리 필터 버튼

- 스타일: 버튼 그룹 또는 태그 형태
- 활성 상태: 배경색 변경, 테두리 강조
- 호버 효과: 배경색 변경

#### 포스트 카드

- 호버 효과: 그림자 증가, 약간의 상승 효과
- 클릭 가능 영역: 전체 카드 또는 제목/썸네일

#### TOC (목차)

- 헤딩 레벨에 따른 들여쓰기
- 현재 섹션 하이라이트
- 스크롤 스파이 기능 (스크롤 위치에 따라 자동 업데이트)
